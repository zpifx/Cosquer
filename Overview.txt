================================================================
COSQUER LANGUAGE OVERVIEW
================================================================

----------------------------------------------------------------
COMMENTS
----------------------------------------------------------------
Comments are delimited by periods (.) on both sides.
They must occupy their own line and cannot share a line with code.
Both the opening and closing period are required.

Examples:
    . This is a comment .
    .This is also valid.
    . A longer comment spanning the full line .

----------------------------------------------------------------
PROGRAM DECLARATION
----------------------------------------------------------------
Every file declares a program name. This acts as the module/
namespace identifier for the file. Other files can reference
its functions and variables using the :: operator.

Syntax:
    program <Name>;

Example:
    program ReturnExample;

----------------------------------------------------------------
FUNCTIONS
----------------------------------------------------------------
Functions use the "function" keyword, with parameters in
parentheses and a return type declared after a colon.
The entry point is always the function named "Start".

Syntax:
    function <Name>(<params>) : <ReturnType> {
        ...
    }

Example:
    function Start(VOID) : INT64 {
        return 0;
    }

- VOID is used both as a parameter type (no parameters) and
  as a return type (no return value).
- A void return uses a bare "return;" with no value.
- A valued return uses "return <expr>;".

----------------------------------------------------------------
FUNCTION CALLS
----------------------------------------------------------------
All function calls use the "call" keyword, whether calling a
local function or one from another program file.

Syntax:
    call <Function>(<args>);
    call <Program>::<Function>(<args>);
    return call <Program>::<Function>(<args>);

Examples:
    call MyLocalFunction();
    call OtherProgram::GetValue();
    return call OtherProgram::GetValue();

----------------------------------------------------------------
NAMESPACE / MEMBER ACCESS OPERATOR
----------------------------------------------------------------
The double-colon (::) operator is used to access functions and
variables from another program, or fields within a struct.

Examples:
    call Math::Sqrt(value);
    myStruct::field

----------------------------------------------------------------
VARIABLES
----------------------------------------------------------------
Variables are declared with "var" (mutable) or "const" (immutable),
followed by the name, a colon, the type, and an initializer.

Syntax:
    var <name> : <Type> = <value>;
    const <name> : <Type> = <value>;

Examples:
    var x : INT64 = 5;
    const maxSize : INT32 = 100;
    var result : INT64 = call OtherProgram::GetValue();

----------------------------------------------------------------
TYPES
----------------------------------------------------------------
Primitive types:

    INT8        8-bit integer
    INT16       16-bit integer
    INT32       32-bit integer
    INT64       64-bit integer
    CHAR        Character (alias for INT8, signals intent)
    BOOL        Boolean
    FLOAT       Single-precision floating point
    DOUBLE      Double-precision floating point
    VOID        No type / no value

Type qualifiers (placed before the type):

    UNSIGNED    Unsigned integer variant (default is signed)
    VOLATILE    Volatile memory (not cached/optimized by compiler)
    REGISTER    Hint to store in a CPU register
    POINTER     Pointer to a type

Examples:
    var x : UNSIGNED INT64 = 0;
    var ptr : POINTER INT32 = ...;
    var flag : VOLATILE BOOL = false;

----------------------------------------------------------------
OPERATORS
----------------------------------------------------------------
Comparison operators (used in conditionals and loops):

    ==      Equal to
    !=      Not equal to
    <       Less than
    >       Greater than
    <=      Less than or equal to
    >=      Greater than or equal to

All standard arithmetic and bitwise operators are also supported:

    +   -   *   /       Arithmetic
    &   |   ^   ~       Bitwise AND, OR, XOR, NOT
    <<  >>              Bitwise shift left / right

----------------------------------------------------------------
CONTROL FLOW
----------------------------------------------------------------

IF / ELSE
    Conditionals compare two values using an operator.

    Syntax:
        if value1 == value2 { ... }
        if value1 != value2 { ... } else { ... }

WHILE
    Loops while a condition is true.

    Syntax:
        while value1 < value2 { ... }

UNTIL
    Loops until a condition becomes true (inverse of while).

    Syntax:
        until value1 == value2 { ... }

FOR
    Counted loop with an initializer, condition, and
    increment or decrement step.

    Syntax:
        for <init>, <init> <op> <limit>, inc(<var>) { ... }
        for <init>, <init> <op> <limit>, dec(<var>) { ... }

    Example:
        for i, i < 10, inc(i) { ... }

REPEAT
    Loops indefinitely until a "break" is called.

    Syntax:
        repeat { ... }

BREAK
    Exits the current loop (used with repeat and others).

    Syntax:
        break;

----------------------------------------------------------------
STRUCTS
----------------------------------------------------------------
Structs group variables under a named type.
Fields are accessed using the :: operator.

Syntax:
    struct <Name> {
        var <field> : <Type>;
        ...
    };

Field access:
    myStruct::fieldName

FULL EXAMPLE
----------------------------------------------------------------

program ReturnExample;

function Start(VOID) : INT64 {
    return 0;
}
